# Лабораторная работа №1 — Простые классы

**Вариант 24:** «Аэропорт», поля — статус и количество взлётно-посадочных полос. Нужны конструктор, методы чтения и изменения полей, вывод данных до и после изменения.

- [airport_basic.cpp](variant-24/airport_basic.cpp) — первоначальная программа `main24.cpp`: два объекта класса `Airport`, геттеры, сеттеры, вывод.
- [airport_extended.cpp](variant-24/airport_extended.cpp) — расширение `main24n.cpp`: дата открытия, определение декады, сезона и века, динамический массив и два конструктора.

Обе программы имеют собственный `main()` и компилируются отдельно:

```bash
g++ -std=c++11 -Wall -Wextra -pedantic variant-24/airport_basic.cpp -o airport_basic
./airport_basic

g++ -std=c++11 -Wall -Wextra -pedantic variant-24/airport_extended.cpp -o airport_extended
./airport_extended
```

Код сохранён в исходном учебном виде. Расширенная версия относится к первой лабораторной, а не ко второй. В ней отсутствует проверка даты, а формула века `(year / 100) + 1` ошибается на годах, кратных ста.
