# Лабораторная работа №2 — Наследование и полиморфизм

Методичка посвящена базовому классу, наследникам, конструкторам дочерних классов, переопределению методов вывода и демонстрации полиморфизма.

**Вариант 14:** базовый класс «Квадрат» (сторона, периметр, площадь, диагональ) и класс-наследник «Куб» (объём, переопределение площади и вывода). Для `N1` квадратов и `N2` кубов требуется найти среднюю площадь квадратов и количество кубов с наибольшей площадью.

Среди предоставленных исходников реализации этой работы нет. Код можно добавить сюда после получения файла. [Оригинальная PDF-методичка](../materials/lab-02.pdf).
