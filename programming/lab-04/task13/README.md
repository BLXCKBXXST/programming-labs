# Степень двойки

Число 1 тоже подходит: это 2⁰. У любой степени двойки в двоичной записи ровно одна единица, поэтому достаточно проверить `n & (n - 1)` (и отдельно исключить ноль).

Например, `8 = 1000₂`, `7 = 0111₂` — побитовое И даёт ноль. А для 6 результат не нулевой.
