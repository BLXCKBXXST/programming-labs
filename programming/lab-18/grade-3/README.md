# Paint++, базовая версия

Реализованы четыре функции рисования: очистка холста, один пиксель, круглая кисть и закрашенный прямоугольник. Всё в [paint_core.cpp](src/paint_core.cpp).

После запуска: B — кисть, R — прямоугольник, E — ластик, C — очистить. Линия, undo и фильтры пока не сделаны — соответствующие функции оставлены как `TODO`.

```bash
cmake -S . -B build
cmake --build build
./build/paint
```

Нужна SFML 2.5.
