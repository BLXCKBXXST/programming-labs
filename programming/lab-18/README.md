# Лабораторная №18 — Графический редактор Paint++

C++17 и SFML. Реализована версия для оценки 3: очистка холста, пиксель, круглая кисть и прямоугольник. Функции следующих этапов в исходниках оставлены как `TODO`.

[Исходники и описание](grade-3/README.md)

## Сборка

Нужны компилятор C++17, CMake и SFML 2.5:

```bash
cmake -S grade-3 -B grade-3/build
cmake --build grade-3/build
./grade-3/build/paint
```

Для Linux библиотеку SFML можно установить через `libsfml-dev`. Работа с графическим окном в WSL требует настроенного графического окружения.
