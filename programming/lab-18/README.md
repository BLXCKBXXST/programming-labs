# Лаба 18 — Paint++

Небольшой графический редактор на C++17 и SFML. Сейчас сделана [версия на 3](grade-3/) с кистью, прямоугольником и очисткой холста. Линия, undo и фильтры в исходниках пока оставлены как `TODO`, не выдаём их за готовые.

Нужны SFML 2.5 и CMake. Сборка из этой папки:

```bash
cmake -S grade-3 -B grade-3/build
cmake --build grade-3/build
./grade-3/build/paint
```
