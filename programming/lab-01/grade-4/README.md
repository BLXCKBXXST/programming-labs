# Температура

Конвертер из °C в °F и обратно. Ввод вида `36.6c` или `98f`, регистр буквы не важен. Формулы обычные: `F = C * 9/5 + 32` и `C = (F - 32) * 5/9`.

[temperature.c](temperature.c), сборка: `gcc temperature.c -o temperature`.

В выводе оставлена опечатка `Ouput`: она есть в эталоне задания.
