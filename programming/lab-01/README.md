# Лаба 1 — условия

Три задачи разной сложности. [На 3](grade-3/leap.c) — определить, високосный ли год. [На 4](grade-4/temperature.c) — перевести температуру между °C и °F. [На 5](grade-5/README.md) — проверить попадание точки в заданную область (вариант 8, «Скорпион»); чертёж рядом с кодом.

`make` собирает первые две программы, `make grade-5` — третью. Там используется `fabs`, поэтому при ручной сборке нужен `-lm`.
