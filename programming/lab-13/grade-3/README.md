# Makefile

Сборка кроссовок через отдельные объектные файлы и статическую библиотеку. Правила прописаны в [Makefile](Makefile), поэтому команды `gcc` и `ar` каждый раз вручную набирать не нужно.

`make` — собрать, `./sneakers` — запустить, `make clean` — убрать результаты сборки.

Напоминание: перед командами в правилах Makefile нужен таб, а не пробелы. `$@` — цель, `$<` — первая зависимость, `$^` — все зависимости.
