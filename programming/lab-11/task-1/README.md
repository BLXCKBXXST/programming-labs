# Указатель и segfault

В [before.c](before.c) функция `init` получает копию указателя и записывает адрес после `malloc` только в неё. Указатель в `main` остаётся `NULL`, отсюда падение при обращении к массиву.

В [after.c](after.c) `init` возвращает выделенный массив, а вызывающий код потом освобождает его через `free`.

`gcc after.c -o after && ./after`
