# Транспонирование дважды

В [before.c](before.c) внутренний цикл идёт по всей матрице, поэтому каждая пара `(i, j)` и `(j, i)` меняется местами два раза. В итоге матрица остаётся прежней.

В [after.c](after.c) цикл начинается с `j = i + 1` — обрабатывается только верхняя половина без диагонали.

`gcc after.c -o after && ./after`
