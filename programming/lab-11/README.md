Четыре задания на поиск и исправление ошибок. Исходные `before.c` намеренно оставлены неисправленными; рабочие версии — `after.c`.

[PDF задания](Лабораторная%20работа%20№11.pdf)

## Сборка

```bash
make
make clean
```

`make` собирает только исправленные версии. Для поиска ошибок можно использовать `gdb`, AddressSanitizer (`-fsanitize=address`) и UndefinedBehaviorSanitizer (`-fsanitize=undefined`).
