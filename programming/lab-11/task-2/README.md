# Переполнение буфера

В исходной программе `sprintf` пишет строку `"1025"` в `char str[4]`. Но нужен ещё завершающий ноль, поэтому запись выходит за пределы массива и может испортить соседнее поле структуры.

[before.c](before.c) оставлен для разбора ошибки; в [after.c](after.c) увеличен буфер и используется `snprintf` с размером массива.

`gcc after.c -o after && ./after`. При отладке исходника можно попробовать `-fsanitize=address`.
