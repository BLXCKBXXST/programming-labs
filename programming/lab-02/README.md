# Лаба 2. Циклы

По варианту вышли алгоритмы 8–12 (`25 % 17 = 8`). Сначала [факториал](alg08_factorial.c), затем [максимальная цифра](alg09_maxdigit.c) и [разворот числа](alg10_reverse.c). На 5 к ним добавляются [целая часть log₂](alg11_log2.c) и [сумма цифр](alg12_digitsum.c).

Для сборки есть `make grade-3`, `make grade-4` и `make grade-5`. Исходные фрагменты из методички сохранены в комментариях к программам.

Факториал считается через `long long`, иначе быстро получаем переполнение.
