# Лабораторная №2 — Циклы

Алгоритмы по варианту 8: номер в группе 25, `25 % 17 = 8`. Исходные фрагменты из методички сохранены в комментариях к программам.

| Оценка | Алгоритмы | Исходники |
|---|---|---|
| 3 | 8 — факториал | [alg08_factorial.c](alg08_factorial.c) |
| 4 | 8–10 — факториал, максимальная цифра, разворот числа | [alg09_maxdigit.c](alg09_maxdigit.c), [alg10_reverse.c](alg10_reverse.c) |
| 5 | 8–12 — дополнительно целая часть `log₂(n)` и сумма цифр | [alg11_log2.c](alg11_log2.c), [alg12_digitsum.c](alg12_digitsum.c) |

## Сборка

```bash
make grade-3
make grade-4
make grade-5
make clean
```

Программы запускаются отдельно: `./alg08_factorial`, `./alg09_maxdigit` и т. д. Для факториала используется `long long`: 13! уже не помещается в 32-битный `int`.
