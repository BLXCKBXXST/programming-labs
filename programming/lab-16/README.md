# Лабораторная №16 — POSIX-потоки

Практическое задание по `pthread`: создание и ожидание потоков, синхронизация, параллельные вычисления и очередь сообщений.

| Оценка | Задания | Папка |
|---|---|---|
| 3 | Упражнения 1–6: создание, join, аргументы, отмена, cleanup, sleepsort | [grade-3](grade-3/README.md) |
| 4 | Упражнения 7–9: синхронизация, умножение матриц, замер времени | [grade-4](grade-4/README.md) |
| 5 | Упражнение 10: FIFO-очередь и многопоточный чат | [grade-5](grade-5/README.md) |
| Дополнительно | Обедающие философы и предотвращение взаимной блокировки | [grade-star](grade-star/README.md) |

[PDF задания](Лабораторная%20работа%20№16.pdf) · [Отчёт с результатами](threads.md)

