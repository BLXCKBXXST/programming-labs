# Первые упражнения с pthread

Здесь шесть отдельных примеров: создание потока, ожидание через `join`, передача аргументов, отмена, cleanup-функция и sleepsort.

Разница между первыми двумя хорошо видна в выводе: без `join` строки потоков могут перемешиваться, с ним родитель ждёт завершения дочернего. В sleepsort каждый поток спит время, зависящее от своего числа. Это учебный трюк, не надёжный алгоритм сортировки.

```bash
make
./ex1_create
./ex2_join
./ex6_sleepsort 5 2 8 1 3
```

Остальные программы запускаются так же, по имени файла без `.c`.
