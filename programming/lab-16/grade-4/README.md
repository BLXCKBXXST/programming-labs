# Мьютексы, матрицы и замеры

Три упражнения: [ex7_sync.c](ex7_sync.c) синхронизирует вывод двух потоков, [ex8_matmul.c](ex8_matmul.c) умножает матрицы с распределением строк между потоками, [ex9_benchmark.c](ex9_benchmark.c) измеряет время того же расчёта.

```bash
make
./ex7_sync
./ex8_matmul 3 2
./ex9_benchmark 200 4
```

[benchmark.py](benchmark.py) запускает серию измерений. [Данные](benchmark.csv) и [график](benchmark.png) лежат здесь же.

В `ex7` ожидание condition variable сделано в `while`, потому что поток может проснуться, даже когда нужное условие ещё не выполнено. А многопоточность на маленьких матрицах не обязательно быстрее: создание и ожидание потоков тоже занимает время.
