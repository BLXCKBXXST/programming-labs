# Обедающие философы

Дополнительная задача на deadlock. В [исходном примере](din_phil.c) все философы могут одновременно взять по одной вилке и зависнуть в ожидании второй.

[Исправленный вариант](din_phil_fixed.c) меняет порядок: чётные берут сначала левую, нечётные — правую. Так убирается циклическое ожидание, хотя гарантии, что всем достанется одинаковое время, нет.

`make && ./din_phil_fixed`

Исходную версию лучше запускать отдельно: она может не завершиться сама.
