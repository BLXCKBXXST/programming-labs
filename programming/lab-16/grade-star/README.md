# Дополнительное задание — Обедающие философы

Пять потоков-философов делят пять вилок. Для приёма пищи каждому нужны две соседние вилки. Если все сначала захватят правую вилку и будут ждать левую, возникнет взаимная блокировка (deadlock).

- [din_phil.c](din_phil.c) — исходный пример с возможной взаимной блокировкой.
- [din_phil_fixed.c](din_phil_fixed.c) — исправленный вариант: чётные философы берут сначала левую вилку, нечётные — правую.

Асимметричный порядок захвата нарушает условие циклического ожидания. Это предотвращает deadlock в данной модели; гарантии справедливости планирования потоков он не даёт.

## Сборка и запуск

```bash
make all
./din_phil_fixed
make clean
```

Исходный `din_phil.c` используется для демонстрации проблемы и может зависнуть. В исправленной версии все 50 порций должны быть распределены между потоками без взаимной блокировки.
