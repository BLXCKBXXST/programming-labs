# Очередь сообщений и чат

По упражнению 10: кольцевая очередь на 10 сообщений, три клиента отправляют текст, два серверных потока его читают. Когда очередь заполнена, отправитель ждёт; когда пуста — ждёт получатель. Для этого используются мьютекс и condition variables.

`msgqueue.c` — сама очередь, `chat.c` — пример работы. Через пять секунд программа останавливает чат. `msgDrop` будит ожидающие потоки, чтобы они могли нормально завершиться.

`make && ./chat`

Сообщения копируются в очередь, а не хранятся как указатели на временные буферы клиентов.
