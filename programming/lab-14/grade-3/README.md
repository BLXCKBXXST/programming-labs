# Односвязный список

Вариант с кроссовками: случайные записи добавляются в конец списка, потом выводятся. Каждый узел хранит данные и указатель `next`. Последний указывает на `NULL`.

`PushBack` принимает `Node **head`, чтобы уметь изменить голову пустого списка. Память для каждого узла выделяется через `malloc` и в конце освобождается.

[main.c](main.c): `gcc main.c -o sneakers_list && ./sneakers_list`. Количество узлов можно передать аргументом, например `./sneakers_list 5`.
