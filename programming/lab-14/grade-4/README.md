# Двусвязный список

По сравнению с предыдущей версией появился указатель `prev` и навигация в обе стороны: D/6 — вперёд, A/4 — назад, Q — выход.

`list.h` находится в [include/](include), реализация — в [src/list.c](src/list.c), запуск — из [src/main.c](src/main.c). Узел отдельно хранит указатель на `Sneaker`, поэтому при удалении нужно освободить и данные, и сам узел.

```bash
gcc src/main.c src/list.c -I include -o sneakers_list
./sneakers_list
```

Отдельная сборка со статической библиотекой предусмотрена Makefile.
