# Два ряда списка

Верхний и нижний списки могут быть разной длины. Между парными узлами есть указатель `cross`, у тех, кому пары не хватило, — `NULL`. Нижний ряд направлен в другую сторону, поэтому навигация получается не совсем обычной.

Клавиши: D/A — вправо и влево, W/S — между рядами, R — вернуться к началу, Q — выход.

```bash
gcc src/main.c src/list.c -I include -o sneakers_list
./sneakers_list 4 3
```

В папке также есть Makefile для сборки через статическую библиотеку.
