# RLE

Дополнительное задание — сжать массив последовательностями вида «значение, сколько раз повторяется». Например, `1 1 1 2 2 3` превращается в `1,3 2,2 3,1`.

[Реализация](rle.c) проверяет несколько случаев: одинаковые числа, все разные, чередующиеся блоки. После распаковки сравнивает результат с исходным массивом.

Когда повторений нет, RLE только увеличивает объём — так и должно быть. `gcc rle.c -o rle && ./rle`.
