# Крамер для произвольного N

Здесь матрица уже динамическая, а определитель считается методом Гаусса с выбором ведущего элемента — иначе для больших N было бы слишком долго. После расчётов память освобождается.

[Код](zadanie3.c) проверялся в том числе на системах 4×4 и 8×8.

Сборка: `gcc zadanie3.c -o grade5 -lm`.
