# Крамер для 2×2 и 3×3

Вводятся матрица коэффициентов и правые части уравнений. Для каждой переменной заменяем соответствующий столбец и делим новый определитель на исходный: `xᵢ = det(Aᵢ) / det(A)`.

В [zadanie2.c](zadanie2.c) предусмотрен случай, когда единственного решения нет.

`gcc zadanie2.c -o grade4 && ./grade4`
