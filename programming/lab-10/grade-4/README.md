# Дроби в трёх файлах

Та же программа, что на 3, только `main.c`, `fraction.c` и `fraction.h` отдельно. В заголовке структура и объявления функций, реализация — в `.c`.

```bash
gcc main.c fraction.c -o fraction
./fraction
```

Если меняется реализация, `main.c` трогать не нужно — он использует функции из заголовка.
