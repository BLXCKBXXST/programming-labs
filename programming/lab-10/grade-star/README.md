# Отдельная сборка через Makefile

Дополнительная часть: исходники из `../grade-4/` компилируются сначала в `.o`, затем объектные файлы связываются в программу. Это позволяет не пересобирать всё при каждом изменении одного `.c`.

Сам [Makefile](Makefile) здесь; достаточно:

```bash
make
./fraction
make clean
```
