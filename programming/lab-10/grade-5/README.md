# Дроби и динамическая память

Здесь число дробей вводится пользователем, под массив выделяется память. Функции работают с указателями на `Fraction`, а в конце массива не должно остаться в памяти.

[main.c](main.c) — ввод и `malloc/free`, [fraction.c](fraction.c) — операции, [fraction.h](fraction.h) — структура и прототипы.

`gcc main.c fraction.c -o fraction_dyn && ./fraction_dyn`

Для трёх дробей `1/2`, `3/4`, `5/6` произведение в текущей реализации — `15/48`. Утечки можно отдельно проверять с `-fsanitize=address`.
