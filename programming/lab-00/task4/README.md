# Исправление ошибок

[before.c](before.c) — сломанный исходник из задания. В нём опечатка в `stdio.h`, отсутствует тип у `main`, не объявлен `x`, перепутаны `print` и `printf`, сломаны кавычки и тип результата `sqrt`.

[after.c](after.c) — исправленный вариант для `x = 0.5`. Должно получиться `The square root of 0.500000 is 0.707107`.

```bash
gcc after.c -o after -lm
./after
```

`-lm` нужен для математической библиотеки с `sqrt`.
