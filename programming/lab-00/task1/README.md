# Форматированный вывод

Повторить вывод из методички, но не вставлять его готовой строкой. В [output.c](output.c) используются ширина поля (`%8d`, `%-8d`) и вывод вещественных чисел.

Для `555` это получается так:

```text
|555|
|     555|
|555     |
```

Ещё здесь видно, что `0.1 + 0.2` в `double` может напечататься как `0.30000000000000004`: числа округляются при хранении в двоичном виде.

Запуск: `gcc output.c -o output && ./output`.
