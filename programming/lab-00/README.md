# Лаба 0. Первые программы

Тут пять маленьких заданий: [Hello World](task0/hello.c), [форматированный вывод](task1/output.c), [переполнение типов](task2/overflow.c), [символы и ASCII](task3/chars.c) и [исправление сломанного кода](task4/README.md).

В последнем задании исходник `before.c` специально не собирается, исправленный вариант — `after.c`.

Собрать всё из этой папки: `make all`. Отдельные задания — `make task1` и т. д.; удалить бинарники — `make clean`.
