# Переполнение

Сравниваем `int`, `unsigned int` и `char` на границах диапазонов. Самое важное: у беззнакового типа переход через максимум определён стандартом, а у знакового переполнения поведение не определено. Поэтому числа из примера на конкретном компьютере — не универсальный результат.

Код в [overflow.c](overflow.c). Для поиска некоторых ошибок можно попробовать собрать с `-fsanitize=undefined`. Диапазоны типов берутся из `limits.h`.
