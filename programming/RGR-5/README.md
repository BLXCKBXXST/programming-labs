# РГР-5. Шифр Полибия

Шифрование и обратная расшифровка текста на C. Латиница — таблица 5×5 (I/J вместе), кириллица — 6×6 без Ё и Ъ, с пробелом. Алфавит программа определяет сама.

В `cipher.c` находятся `Polibi` и `DePolibi`, `main.c` отвечает за ввод и проверку, что расшифрованный текст совпал с исходным. Библиотека собирается отдельно в `libcipher.a`.

```bash
make
./polibi
```

Например, для `HELLO` программа выводит пары координат букв, а потом восстанавливает исходную строку. Очистка — `make clean`.
