# Чтение CSV

Программа получает путь к файлу аргументом, разбирает записи с разделителем `;` и выводит сотрудников с ID и уровнем. Строки, в которых не хватает полей, пропускаются.

Есть две реализации: [main.c](main.c) через `fgets`/`strtok` и [main_syscall.c](main_syscall.c) через `open`, `read`, `write`, `close`. Обе можно собрать обычным `make`.

```bash
./program staff.csv
./program_syscall staff.csv
```

[staff.csv](staff.csv) — тестовый файл. Если не передать путь или указать несуществующий файл, программа выдаст ошибку.
