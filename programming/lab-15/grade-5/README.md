# CSV, DAT и RLE

Продолжение работы с базой сотрудников. Программа умеет загружать CSV, бинарный DAT и сжатый RLE. В меню можно искать сотрудника по ID, выводить все записи и сохранять их в другом доступном формате.

`main.c` определяет тип файла, `record.c` занимается записями и сжатием, `menu.c` — меню. В RLE повторяющиеся байты хранятся парами `(количество, значение)`.

```bash
make
./program staff2.csv
./program database.dat
./program database.rle
```

Ещё один пример данных — [staff.csv](../grade-3/staff.csv). DAT и RLE появляются после соответствующих действий в программе.
