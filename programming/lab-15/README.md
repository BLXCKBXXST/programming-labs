# Лабораторная №15 — Текстовые и бинарные файлы

Обработка базы сотрудников: имя, идентификатор и уровень (Level_A / Level_B / Level_C). Входные данные — CSV с разделителем `;`.

| Оценка | Задание | Папка |
|---|---|---|
| 3 | Чтение и вывод CSV; дополнительный вариант на системных вызовах | [grade-3](grade-3/README.md) |
| 4–5 | Бинарный файл, поиск по ID, RLE-сжатие и восстановление | [grade-5](grade-5/README.md) |

Отдельной папки `grade-4` нет: её функции реализованы в `grade-5`.

[PDF задания](Лабораторная%20работа%20№15.pdf)

## Сборка

```bash
make all
make grade-3
make grade-5
make clean
```

Примеры данных: [staff.csv](grade-3/staff.csv) и [staff2.csv](grade-5/staff2.csv).
