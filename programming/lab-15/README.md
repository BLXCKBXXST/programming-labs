# Лаба 15 — файлы

Небольшая база сотрудников из CSV: имя, ID и уровень. [Первый вариант](grade-3/) читает и выводит записи; там же есть версия без stdio, на системных вызовах. [Следующий](grade-5/) сохраняет данные в бинарный файл, ищет по ID и делает RLE-сжатие.

Папки `grade-4` отдельно нет: соответствующая часть уже включена в `grade-5`. Для проверки лежат [staff.csv](grade-3/staff.csv) и [staff2.csv](grade-5/staff2.csv).

Сборка — `make all`. [PDF задания](Лабораторная%20работа%20№15.pdf).
