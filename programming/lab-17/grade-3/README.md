# Тесты через assert

Самый простой вариант проверки [tinyexpr](../external/tinyexpr/): передаём строку с выражением, сравниваем результат с ожидаемым. Здесь 12 тестов — арифметика, скобки, функции и несколько ошибок парсера.

`make run`

Если проверка не проходит, `assert` сразу останавливает программу. В следующих вариантах для этого уже используется CMocka.
