# Те же тесты, но с CMocka

Пять групп проверок: корректные выражения, неправильный ввод, деление на ноль, квадратный корень из отрицательного числа и тригонометрическое тождество. Даже если одна группа не проходит, остальные продолжают выполняться.

На Debian/Ubuntu нужна `libcmocka-dev`. После установки — `make run`.

[Исходник](test_cmocka.c). Внутри есть табличные тесты, чтобы новые выражения добавлялись без копирования одинаковых функций.
