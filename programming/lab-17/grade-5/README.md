# Расширенные тесты tinyexpr

Здесь 23 отдельные проверки арифметики, скобок, степеней, встроенных функций, тригонометрии и ошибочных выражений. Используется CMocka, а общий CMake регистрирует тесты для CTest.

Важная особенность именно этой версии tinyexpr: `2^3^2` вычисляется слева направо и даёт 64, не 512. Под это есть отдельный тест — он фиксирует текущее поведение библиотеки.

Запускать из родительской папки `lab-17/`:

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Если нужен вывод каждого теста, можно добавить `-V`.
