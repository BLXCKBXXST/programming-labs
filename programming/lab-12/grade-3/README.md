# Кроссовки, всё в одном файле

Массив из десяти кроссовок со случайными брендами, моделями, размерами и ценами. Сначала печатаем исходный порядок, потом сортируем по цене пузырьком и печатаем снова.

[main.c](main.c), запуск: `gcc main.c -o sneakers && ./sneakers`.

Пузырёк выбран по заданию: алгоритм простой, хотя для больших массивов медленный.
