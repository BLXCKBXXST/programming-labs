# Лабораторная №12 — Библиотеки и многофайловый проект

| Оценка | Реализация | Папка |
|---|---|---|
| 3 | Все функции в одном файле | [grade-3](grade-3/README.md) |
| 4 | Заголовок и исходники, статическая библиотека | [grade-4](grade-4/README.md) |
| 5 | Динамическая библиотека и замер времени сортировки | [grade-5](grade-5/README.md) |
| Дополнительно | Передача функции сравнения в сортировку | [grade-star](grade-star/README.md) |
