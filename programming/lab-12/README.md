# Лаба 12 — библиотеки

Опять вариант с кроссовками (бренд, модель, размер, цена). Задача та же — сортировка массива, но меняется способ организации кода.

[На 3](grade-3/) — один файл, [на 4](grade-4/) — статическая библиотека, [на 5](grade-5/) — динамическая библиотека и сравнение времени сортировки. [Дополнительно](grade-star/) — сортировка с функцией сравнения.

`make all` собирает все варианты. Исходная [методичка](Лабораторная%20работа%20№12.pdf) рядом.
