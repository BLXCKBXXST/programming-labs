# Матрица без строки и столбца максимума

Версия на статических массивах. Вводится матрица, находится максимальный элемент, его строка и столбец вычёркиваются. В получившейся матрице считаем строки с нулями и печатаем главную диагональ с конца.

Для матрицы

```
1 2 3
4 9 5
6 7 8
```

получится `1 3 / 6 8`, строк с нулями — 0, обратная диагональ — `8 1`.

[Код](zadanie1.c). `gcc zadanie1.c -o zadanie1`.
