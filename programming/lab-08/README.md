# Лабораторная №8 — Матрицы и динамическая память

Оригинальная PDF-методичка для этой работы отсутствует. Условие ниже восстановлено по сохранённому коду, а не по тексту методички.

В прямоугольной матрице нужно найти максимальный элемент, удалить его строку и столбец, затем вывести полученную матрицу, количество строк с нулями и её главную диагональ в обратном порядке.

| Оценка | Реализация | Исходник |
|---|---|---|
| 4 | Статические массивы | [grade-4/zadanie1.c](grade-4/zadanie1.c) |
| 5 | Функции и динамическая память (`malloc`/`free`) | [grade-5/zadanie1.c](grade-5/zadanie1.c) |

## Сборка

```bash
gcc -std=c11 grade-4/zadanie1.c -o grade-4/zadanie1
gcc -std=c11 grade-5/zadanie1.c -o grade-5/zadanie1
```

Примеры ввода и выводов — в README соответствующих версий.
