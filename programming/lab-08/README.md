# Лаба 8. Матрицы

Находим максимальный элемент матрицы и вычёркиваем его строку и столбец. В полученной матрице считаем строки с нулями и выводим главную диагональ в обратном порядке.

Две версии одного решения: [на обычном массиве](grade-4/zadanie1.c) и [с выделением памяти через malloc](grade-5/zadanie1.c).

Оригинального PDF у этой работы пока нет. Условие восстановлено по сохранённому коду, так что лучше сверить с методичкой, если она найдётся.
