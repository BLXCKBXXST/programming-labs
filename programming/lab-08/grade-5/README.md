# Та же матрица, но с malloc

Задача как в [версии на 4](../grade-4/), только матрица выделяется динамически, а поиск максимума, создание минора и остальные действия вынесены в функции.

Из исходного варианта убраны незаконченные строки с указателями, из-за которых программа не компилировалась.

[Исходник](zadanie1.c), сборка: `gcc zadanie1.c -o zadanie1`. Не забываем про `free` для всех выделенных строк матрицы.
