# Лабораторная №15.2 — Отладка

Пять заданий из ветки [debug_task](https://github.com/kruffka/C-Programming/tree/debug_task) и дополнительная задача с симулятором 4G/5G. Первые четыре повторяют задачи [лабораторной №11](../lab-11/README.md).

| Оценка | Задания |
|---|---|
| 3 | Два из `task1`–`task4` |
| 4 | Все `task1`–`task4` |
| 5 | Дополнительно `task5` с ошибками в шифровании |
| Дополнительно | `task_star`: симулятор сети и проверка санитайзерами |

Все исходники лежат в [src/](src). Ошибки первых четырёх программ разобраны в README соответствующих заданий лабораторной №11. В `task5` исправляются выходы за границы массивов, неверные диапазоны символов и путаница между `sizeof` и `strlen`. Подробный разбор симулятора — в [DEBUG_LOG.md](DEBUG_LOG.md).

## Сборка и проверка

```bash
make all
./src/task1
./src/task2
./src/task3
./src/task4
./src/task5
./src/task_star
make clean
```

Makefile включает AddressSanitizer и UndefinedBehaviorSanitizer. Программы должны завершаться без их ошибок.
