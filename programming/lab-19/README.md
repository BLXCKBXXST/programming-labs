# Лабораторная №19 — Консольный банкомат

Проект на C++17: консольный интерфейс, операции со счётом, журнал транзакций и восстановление данных после сбоя.

## Запуск

Из папки `lab-19/`:

```bash
bash run.sh
```

Из корня репозитория: `bash programming/lab-19/run.sh`. Для сборки нужны CMake 3.20+ и компилятор C++17 (Linux/macOS).

## Тестирование

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Тестовые карты и PIN-коды определены в исходниках. Здесь используются демонстрационные данные, а не настоящие банковские реквизиты.
