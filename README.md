# Учебные предметы

Лабораторные и расчётно-графические работы по разным дисциплинам. Каждый предмет находится в своей папке, у каждого — собственное оглавление, задания и исходники.

| Предмет | Папка | Содержимое |
|---|---|---|
| Программирование | [programming/](programming/README.md) | Лабораторные работы №0–19, РГР и материалы по C / C++ |
| Объектно-ориентированное программирование | [oop/](oop/README.md) | Лабораторные по ООП на C++, исходники и PDF-методички |

## Структура

```text
.
├── programming/
│   ├── README.md
│   ├── .vscode-setup/
│   ├── lab-00/ ... lab-19/
│   ├── RGR-5/
│   └── RGR-15/
├── oop/
│   ├── README.md
│   ├── lab-01/
│   ├── lab-02/
│   └── materials/
│       ├── lab-01.pdf
│       └── lab-02.pdf
└── .gitignore
```

Для запуска программ и требований к сборке откройте README соответствующего предмета.
