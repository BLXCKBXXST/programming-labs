# САОД

Лабы по структурам и алгоритмам на C. Здесь 15 программ: сначала сортировки и поиск в массивах, потом списки и хеширование.

[Массивы, 1.1–1.10](src/arrays/) — от сортировки выбором до QuickSort, плюс двоичный поиск и индексация. [Списки, 2.1–2.5](src/lists/) — стек, очередь, слияние, цифровая сортировка и два способа хеширования.

В сортировках считаются пересылки (M) и сравнения (C), затем результаты сопоставляются с теорией из методички.

Собирается из этой папки:

```bash
make
./build/bin/1_1_select_sort
```

Необязательно собирать всё: например, `make quick` или `make hash_open`. Полный список целей — `make help`. Результаты сборки удаляются через `make clean`. Есть ещё `make pack` и `make unpack` для упаковки исходников в `project.pack`.

Методички: [массивы](docs/arrays.pdf), [списки](docs/lists.pdf), [трудоёмкость](docs/labor_intensity.pdf) и [основное пособие](docs/methodical%20manual.pdf). Отдельно сохранился [конспект](docs/Конспект.md).
