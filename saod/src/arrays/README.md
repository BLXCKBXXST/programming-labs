# Массивы

Первая часть САОД, задачи 1.1–1.10. Почти везде сравниваются M (пересылки) и C (сравнения) для разных исходных массивов.

Начинается с [выбора](1_1_select_sort.c) — обычного и улучшенного. Дальше [пузырёк](1_2_bubble_sort.c), [шейкер](1_3_shaker_sort.c), [включение](1_4_insert_sort.c) и [Шелл](1_5_shell_sort.c) с разными последовательностями шагов.

В [1.6](1_6_binary_search.c) несколько вариантов двоичного поиска, в [1.7](1_7_struct_sort.c) сортируется телефонный справочник по составному ключу. [1.8](1_8_index_sort.c) — индексные массивы без перестановки исходных записей. Последние две — [HeapSort](1_9_heap_sort.c) и [QuickSort](1_10_quick_sort.c); у быстрой сортировки сравниваются два способа выбора опорного элемента.

Например, из папки `saod/`:

```bash
make select
./build/bin/1_1_select_sort
```

Или `make 1_10_quick_sort`, если нужна только десятая работа. Общие функции находятся в [sorting.c](../../lib/sorting.c) и [search.c](../../lib/search.c). Исходное [задание](../../docs/arrays.pdf) и [таблица трудоёмкости](../../docs/labor_intensity.pdf) лежат в `docs/`.
