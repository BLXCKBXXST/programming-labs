# Списки и хеширование

Вторая часть, задачи 2.1–2.5. Тут уже не только сортировки: есть работа с указателями, стеком, очередью и хеш-таблицами.

[2.1](2_1_list.c) — операции со списком, контрольная сумма, число серий и обратный вывод. В [2.2](2_2_merge_sort.c) сортировка слиянием, в [2.3](2_3_digital_sort.c) цифровая сортировка целых чисел и фамилий. [2.4](2_4_hash_chain.c) — хеширование с цепочками, [2.5](2_5_hash_open.c) — открытая адресация с линейными и квадратичными пробами. В последней задаче таблица специально меньше набора ключей: можно посмотреть, что произойдёт при заполнении.

Запуск из `saod/`, например:

```bash
make merge
./build/bin/2_2_merge_sort
```

Для хеширования есть `make hash_chain` и `make hash_open`. Сама работа со списками вынесена в [list.c](../../lib/list.c), с таблицами — в [hash.c](../../lib/hash.c).

[Методичка по этой части](../../docs/lists.pdf). Для сравнения измерений M и C — [теоретические значения](../../docs/labor_intensity.pdf).
